# JI BUS — 청주시 버스정보 시스템

청주시 공공데이터 API를 이용하는 모바일 우선 버스정보 웹 애플리케이션입니다.

## 실행

- 운영: https://doldolx2.github.io/JI_BUS/
- 별도 서버·계정은 없으며 GitHub Pages에서 정적 파일로 서비스합니다.
- 버스정보 API 인증키는 Vercel 중계 서버에서 관리합니다. 사용자는 별도 키를 입력하지 않습니다.
- 위치 기반 스마트 추천과 날씨는 HTTPS, 브라우저 위치 권한 및 네트워크 연결이 필요합니다. 날씨의 지역명 표시는 브라우저에서 BigDataCloud 역지오코딩 API로 GPS 좌표를 전송해 처리합니다(위치 권한 허용 시). 좌표 및 변환된 지역명은 브라우저 저장소에 보존하지 않습니다.
- 즐겨찾기와 최근 검색은 해당 브라우저의 `localStorage`(`ji-bus-v1`)에 보관됩니다. 기존 브라우저에 저장된 개인 TAGO API 키는 Build 09 첫 실행 시 제거됩니다. 서버에 사용자별 집계나 즐겨찾기를 저장하지 않습니다.

## 주요 기능

- GPS 기반 스마트 직행 추천, 실시간 도착·버스 위치, 정류장명 유사 검색
- 출발지·도착지 직행 검색(초기 최대 6개 노선 상세 조회, 유효 직행 후보 최대 3개 비교)
- 사용자 요청 시 추가 직행 및 환승 검색
- 최근 검색·즐겨찾기·주변 정류장 검색·GPS 지역명 기반 날씨
- 진행 상태·검색 취소·요청 실패 재시도·15초 도착정보 갱신
- 인트로 5초 카운트다운과 모바일 라이트 테마

**주의:** 초기 우선 추천은 제한된 후보에서 비교한 결과이며 전체 노선 중 절대적인 최적 경로를 보장하지 않습니다. 실제 버스 이용 전 정류장과 운행 방향을 확인하세요.

## 개발자 진단

**설정 → 개발자** 버튼에서 고정 PIN `6554`를 입력합니다. 검색당 경과시간, API 요청 횟수, 후보 수, 오류 수를 확인할 수 있습니다. 기록은 메모리에만 존재하며 페이지를 닫으면 사라집니다.

PIN은 사용 편의를 위한 **클라이언트 메뉴 진입 제한**일 뿐, 서버 인증·보안 기능이 아닙니다. JavaScript에서 PIN을 확인할 수 있고 Vercel에 보관된 API 키를 보호하지 않습니다. 공개 API의 남용 방지는 서버 방화벽 규칙으로 별도 적용합니다.

## 로컬 실행 및 검증

프로젝트 루트에서:

```powershell
python -m http.server 8000
```

이후 `http://localhost:8000` 접속. GPS는 HTTPS 또는 보안 컨텍스트가 필요하며, 휴대전화에서 PC의 사설 IP로 접속하면 위치 권한이 동작하지 않을 수 있습니다.

```powershell
Get-ChildItem .\tests\*.test.cjs | ForEach-Object { node $_.FullName }
```

운영 배포는 `feature/v1.0`(GitHub Pages 운영 브랜치)에 PR로 병합한 후 `main`을 동일 커밋으로 동기화합니다. 각 개발은 버전·빌드별 브랜치에 분리합니다.
