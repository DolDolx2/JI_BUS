# JI BUS V1.4 Build 08 — 오창대읍 표기 오류 보정

- 브랜치: feature/v1.4-build08-weather-locality-correction
- 버전: V1.4 Build 08 / 20261123.1408
- 기준: V1.4 Build 07 / 68b308f7861f657a9cf5fcb4892db02f444bc523

## 문제
지역명 역지오코딩 결과가 사용자 휴대전화에서 '청주시 오창대읍'으로 표시됨.
'오창대읍'은 2021년 오창읍 4급 행정체제(대읍) 승격을 지칭하는 표현이며, 공식 지명은 '오창읍'.
참고: 청주시 행정구역 자료, https://www.newsis.com/view/NISX20210501_0001426833

## 수정
- 외부 주소 서비스에서 '오창대읍'이 반환되어도 UI는 법정 지명 '오창읍'으로 표시.
- 응답 localityInfo.administrative에 유효한 구 명칭이 있을 경우 시·구·읍/동 조합에 표시.
- 다른 행정구역명은 임의로 치환하지 않으며 기존 GPS·기온 조회 과정은 변경하지 않음.
- 버전 식별자, cache-busting, 회귀 테스트 갱신.

## 검증
12개 테스트 파일, 코드·모의 API 기반 267개 항목 PASS.
'청주시 오창대읍' → '청주시 오창읍' 및 '청원구' 응답 포함 시 '청주시 청원구 오창읍' 검증.

## 남은 UAT
- Android 기기에서 지역명 오창읍 표기 확인.
- 10°C 기온이 실제 기기 위치와 일치하는지 판단하려면 날씨 데이터 관측 시각/API 응답을 별도로 검증해야 함.
- 역지오코딩 위치 정확도는 GPS 권한 및 외부 API 품질에 따라 달라짐.
