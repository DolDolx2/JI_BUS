# JI BUS V1.5 Build 01 — 공공데이터 서비스 자동 연결 관리

## 사용자 요청과 최종 정책
- 설정 화면의 서비스 연결 확인 버튼 및 인증키·API 등 기술 안내 문구 제거.
- **현재 상태**와 **마지막 확인 시각**만 표시.
- 기존 **개발자 버튼, 비밀번호, 진단 메뉴**는 그대로 유지.
- 앱 시작과 화면 복귀 시 배경에서 실제 공공데이터 버스 목록(청주시 코드 33010) 조회로 연결 확인.
- 정상 연결 상태에서는 5분마다 재확인.
- 실패 시 자동 재시도: **1~3회 3초 간격 / 4~6회 10초 / 7회 이상 30초**. 호출 제한(HTTP 429) 발생 시 서버의 `Retry-After`와 최소 60초 간격을 우선.
- 브라우저가 오프라인이면 요청을 보내지 않고 연결 상태 안내. 인터넷 재연결 이벤트에서 즉시 확인.
- 페이지가 백그라운드로 전환되면 주기 확인 타이머를 정지하고, 복귀 시 즉시 확인.
- 검색 진행 모달과 자동 연결 검사를 분리하여 검색 취소가 연결 검사에 영향을 주지 않음.
- 연결 회복으로 이전 인증 차단 상태가 해제되면 가능한 경우 버스 도착정보 조회 재개.

## 사용자 메시지
- 연결 중: '공공데이터 서비스 연결을 확인하고 있습니다.'
- 정상: '공공데이터 서비스에 정상 연결되었습니다.'
- 일시 장애: '연결이 원활하지 않습니다. 자동으로 다시 연결합니다.'
- 장시간 장애: '공공데이터 서비스에 연결할 수 없습니다. 자동 재연결 중입니다.'
- 오프라인: '인터넷 연결을 확인할 수 없습니다. 연결되면 자동으로 다시 확인합니다.'
- 마지막 확인 시각: '마지막 확인 HH:MM'
