# JI BUS V1.4 Build 11 — 네이버지도 연결 복원 및 대체 하차지 종료

## 수정 원인
- Build 10 기준 네이버지도 연결은 스마트 추천의 접힌 상세 내용에서만 가능했음.
- 일반 직행·환승 결과 카드에는 지도 호출 버튼이 없어 사용자가 기능이 사라졌다고 판단함.
- 과거 즐겨찾기에 남은 `alt` 필드는 Build 10부터 검색에는 사용하지 않지만 브라우저 저장소에 그대로 남아 있었음.

## 변경 내용
1. 직행·환승 검색 카드 하단에 **네이버지도 길찾기** 및 **지도 웹 보기** 링크 복구. 상세 타임라인을 펼치지 않아도 이용 가능.
2. 스마트 추천의 상세 보기에도 출발 정류장→하차 정류장 대중교통 길찾기를 추가. 기존 출발 정류장까지의 도보 안내 링크 유지.
3. 네이버 공식 `nmap://route/public` 딥링크를 사용. 좌표·정류장명을 전달해 대중교통 길찾기를 요청하되, 네이버 자체 검색 결과가 JI BUS의 추천 노선과 완전히 같다는 보장은 없음.
4. 지도 앱 미설치 또는 딥링크를 지원하지 않는 브라우저를 위해 별도 `https://map.naver.com/p/search/...` 웹 지도 링크 제공. 웹 링크는 **하차 정류장 검색 페이지**이며 앱 딥링크의 대중교통 경로와는 다름.
5. 이미 저장된 즐겨찾기의 기존 `alt` 필드는 앱 첫 실행 시 삭제. 출발·도착 정류장, 이름, 정렬 순서는 보존.
6. 과거 개인 설정의 `cfg.stops.alt` 필드도 제거. 별도 저장된 대체 하차 목적지 즐겨찾기는 그대로 유지.
7. 새 즐겨찾기 생성 및 기존 이관 로직에서 `alt` 속성 생성을 완전히 중단.
8. TAGO/Vercel/기상청 연동, 사용자 데이터의 다른 속성, 버스탐색 로직(Build 10) 변경 없음.

## 테스트
- 총 16개 코드·모의 데이터 테스트, 333개 검증 항목 통과.
- 신규 테스트: 네이버 지도 URI 경로 및 URL 인코딩, 좌표 검증, 중복 링크 방지, 기존 즐겨찾기 `alt` 삭제 및 별도 즐겨찾기 유지.
- Android 네이버지도 앱의 실제 설치/실행 여부 및 브라우저별 딥링크 반응은 UAT로 확인 필요.
