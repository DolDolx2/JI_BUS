# JI BUS V1.4 Build 09 — Vercel API gateway & 기상청 관측 기온

## 배포 구조
- 운영 화면: GitHub Pages `https://doldolx2.github.io/JI_BUS/`
- API 중계 서버: Vercel 프로젝트 `ji-bus-api`, 서울 리전 `icn1`
- 허용된 TAGO API와 기상청 초단기실황 API만 중계합니다.
- Vercel 환경변수: `TAGO_API_KEY`, `KMA_API_KEY`. 두 키는 Vercel Sensitive로 등록되어 있으며 GitHub에 저장하지 않습니다.
- Vercel WAF: `/api/` 경로에 IP별 240회/60초 고정 윈도우 제한. 악의적인 분산 공격이나 공공데이터 원본 전체 호출량 제한을 완전히 방지하는 장치는 아닙니다.
- 버스 API 요청: `https://ji-bus-api-siga0411-6093.vercel.app/api/bus` (service/method allowlist, 파라미터 검사, 공개 요청 캐시 15초)
- 기온 API 요청: `https://ji-bus-api-siga0411-6093.vercel.app/api/temperature?lat=...&lon=...` (기상청 T1H, 캐시 10분)
- 기존 `index.html` 및 앱 화면은 GitHub Pages에서 그대로 제공합니다. **Vercel API 서버의 Production 배포 확인 후 프런트엔드 활성화해야 합니다.**

## 앱 변경
1. 사용자의 API 키 입력·저장 UI 제거. 기존 저장소 `ji-bus-v1`의 `key` 필드만 최초 실행 시 삭제하며 즐겨찾기·최근 검색은 보존.
2. `api()` 공용 호출을 직접 TAGO에서 Vercel 중계로 변경. 전체 정류장·노선·도착정보 기능 동일 API 결과 구조를 유지.
3. 설정에 `버스정보 서비스 연결 확인` 버튼 추가, 개발자 진단 메뉴·고정 PIN 6554 유지.
4. Open-Meteo에서 기온과 날씨를 모두 받던 방식에서 **기상청 T1H 기온을 우선**으로 변경.
5. Open-Meteo는 날씨 상태(맑음·흐림 등)를 유지하고, 기상청 장애나 관측시각 만료 시 대체 기온을 제공합니다.
6. 사용자 화면에 기상청 관측 기준시각 또는 Open-Meteo 대체 사용 사유를 표시합니다.
7. GPS 지역명 기능(Build 07·08)은 변경하지 않았습니다.

## 주의
- T1H는 약 5km 격자의 관측 기반 지역 대표값이며 기상청 1시간 단위 갱신/발표 지연이 있습니다.
- GPS 실패 시 청주시 대표 좌표로 대체합니다. 이때 상단에 '청주시 기준' 표기 유지.
- 서로 다른 도메인에서 요청하므로 CORS는 `https://doldolx2.github.io`만 허용. CORS는 인증 또는 남용 방지 수단이 아닙니다.
- Vercel API는 공개 URL을 갖게 됩니다. WAF 사용량과 공공데이터 API 제공처 쿼터를 주기적으로 확인해야 합니다.
- 북마크나 사용자가 저장한 구간의 운영 상태를 임의로 수정하거나 삭제하지 않습니다.
