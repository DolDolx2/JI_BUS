## 사용자 UAT
상단 한 줄 헤더 적용 후 휴대전화에서 갱신 버튼이 보이지 않음.

## 수정
- 검색 탭 전용으로 갱신 버튼을 숨기던 JS 두 군데 제거.
- 상단 헤더 오른쪽 40px 폭을 갱신 아이콘용으로 확보.
- 모바일에서 갱신 문구는 숨기되 아이콘은 항상 표시. 접근성 레이블 유지.
- 홈: 시각, 날씨 캐시 무효화 및 최근 검색 새로고침.
- 직접 검색: 현재 검색 결과의 실시간 도착정보 갱신.
- 스마트 추천: 선택된 목적지가 있을 때 추천 다시 검색.
- 즐겨찾기: 목록 렌더 갱신.
- 설정: 현재 설정정보 안내.
- 코드 파싱 및 6개 테스트 묶음 143개 계약 검증 통과.
