# JI BUS V1.4 Build 07 — 현재 위치의 지역명 표시

- 버전: V1.4 Build 07 / 20261123.1407
- 개발 브랜치: feature/v1.4-build07-weather-region
- 기준: V1.4 Build 06 / acd14bcd486fa24d8ffe2e6b319b0c26b65af7bf

## 변경
1. 날씨 상단 타이틀을 정적인 '청주시 시내버스'에서 GPS 기반 지역명으로 대체.
2. 기온 앞 '현재 위치' 문구 제거. 예: 상단 `⌖ 청주시 복대동`, 본문 `8°C · 대체로 맑음`.
3. BigDataCloud의 브라우저 전용 무료 역지오코딩 API를 이용해 GPS를 도시·동네 이름으로 변환. 추가 API 키·서버 불필요.
4. 시·동 이름이 중복되면 하나만 표시, 구체 지명이 불가능하면 반환된 시/도 수준까지 표시. 긴 지명은 모바일에서 말줄임표 처리.
5. GPS 미허용/실패면 기존의 청주시 기준 좌표로 날씨를 조회하고 상단도 '청주시 기준'으로 표시.
6. 지역명 API 오류 시에도 GPS 기반 기온을 보존하며 '위치 확인됨 · 지역명 미확인'으로 표시.
7. GPS 기온 요청 실패 후 청주 기준 날씨로 대체했을 때 지역명 역시 '청주시 기준'으로 유지(비동기 경쟁 상태 방지).
8. 지역명 성공 조회는 약 20분·1km 이내 재사용. 위치 및 주소는 브라우저 저장소에 기록하지 않음.
9. 날씨 정보의 출처 펼침에 BigDataCloud 출처 추가.

## 개인정보 및 제약
- 역지오코딩을 위해 브라우저가 GPS 권한을 받은 경우에만 위도·경도 좌표가 외부 BigDataCloud API에 전달됩니다.
- 제공자에 따라 행정동 명칭 또는 한국어 표기가 불완전할 수 있습니다.
- BigDataCloud는 주소 응답을 제공하지만 이 앱에서는 거리 주소·사용자 좌표를 저장하지 않습니다.
- 서비스 참고: https://www.bigdatacloud.com/docs/free-api/free-reverse-geocode-to-city-api

## 검증
- 모의 API·코드 기반 전체 회귀 검증: 12개 테스트 묶음 265개 항목 PASS.
- 신규 지역명 포맷/중복 제거/요청 파라미터 테스트 포함.
- 실제 휴대전화 위치 권한, 지역명 응답, Open-Meteo 응답 및 모바일 출력은 사용자 UAT 필요.
