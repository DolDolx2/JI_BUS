# JI BUS V1.4 Build 12 — 정류장 도보 지도 및 도착정보 명확화

## 문제 재현
- Build 11에서 네이버지도 링크가 정류장→정류장 대중교통 길찾기로 변경됨. 원래 사용 목적은 **현 위치에서 탑승 정류장까지 도보 경로 안내**임.
- TAGO 실시간 도착정보는 개별 정류장에 대해 현시점 예측 차량만 제공한다. 해당 노선 차량이 운행 중이어도 조회 정류장의 도착예정정보가 빈 목록일 수 있음.
- 2026-11-23에 실제 운영 Vercel API에서 코오롱하늘채아파트(1151, CJB270000619)의 731번 도착정보는 미제공, 731번 노선 차량 위치는 3대 조회. 삼성SDI(4061)의 731번 도착정보는 정상 조회됨. 서로 다른 정류장의 ETA를 이동해 표시하는 것은 금지.

## 수정
1. 일반 직행/환승 카드의 ‘정류장까지 도보 길찾기’는 오직 **탑승 정류장 좌표**를 네이버지도 `nmap://route/walk`에 전달. 스마트 추천은 기존 정류장 도보 길찾기 유지.
2. ‘정류장 위치 웹 보기’는 별도 웹 검색 링크임을 명시(실제 도보 경로 계산 아님). 버스 출발지→목적지 대중교통 경로 링크 제거.
3. 탑승 정류장 도착정보가 없으면 카드 기온/ETA 표시를 추정하지 않고 '예정시간 미제공'으로 명시.
4. 별개 위치 API의 차량 정보는 방향 및 운행 순서 검증 후 '탑승 방향 차량', '정류장 접근 후보' 또는 '노선 차량 위치 확인·방향 미확인'으로 구분해 표시. 차량이 운행 중이라는 이유만으로 ETA를 계산하지 않음.
5. 조회 API 오류와 운행 중단, 도착시간 미제공을 혼동하지 않도록 메시지 구분.
6. 기존 즐겨찾기, Build 10 검색 로직, Vercel API, 기상청 기온은 변경하지 않음.

## 검사 및 UAT
- 기존 및 신규 총 **17개** 코드/모의 API 테스트 파일, **344개** 검증 항목 통과.
- 지도에 하차지 좌표가 포함되지 않음, 중복 지도 링크 없음, 대체 목적지 즐겨찾기 유지 확인.
- 모바일 실물 네이버지도 앱 딥링크 실행은 UAT 필요.
- 실제 TAGO 731번은 코오롱하늘채 탑승 정류장에서 ETA를 반환하지 않을 수 있다. 앱은 위치 정보만 표시하며 분 단위 도착예정은 임의 추정하지 않음.
