# JI BUS V1.4 Build 06 — 안정화·간소화 작업 인계서

기준 버전: V1.4 Build 05 (commit 4b36d46cb0ef39196ed96560f459e19765bcb350)
개발 브랜치: feature/v1.4-build06-stabilization
버전: V1.4 Build 06 / 20261122.1406

## 승인 범위 및 변경
1. **직행 노선 추천 정확도**: 목적지 경유 노선 최대 6개 상세 조회 범위 안에서 직행 3개 노선까지 비교. 실제 도착시간(알 수 있을 때) 우선, 데이터가 없으면 이동 정류장 수 및 노선번호로 보조 정렬. 여전히 전 노선 완전탐색이 아니므로 '우선 추천' 표기 유지.
2. **검색 취소 안정화**: 탭 전환과 스마트/직접 모드 전환 시 활성 검색 요청 취소 및 기존 취소 콜백 처리. 오래된 요청 결과의 업데이트 차단 로직 유지.
3. **간결한 스마트 추천 카드**: 버스번호·실시간 도착시간·탑승/하차·도보/정류장 수 중심. 상세정보, 이동시간 가정, 지도 버튼은 접기/펼치기 하단으로 배치. '이 경로 보기' 버튼은 언제나 표시.
4. **중복 UI 삭제**: 홈 화면 버스 이용 안내 카드, 스마트 검색 반복 안내문, 최근 검색 보관 방식 설명, '버스 검색' 중복 제목 제거. 검색 결과 구간 제목 단일 행.
5. **초기 입력 빈칸**: 마지막 검색 구간을 자동으로 검색 입력란에 복원하는 동작 제거. 최근 검색 및 즐겨찾기 저장/불러오기는 유지.
6. **개발자 진단 메뉴**: 설정 → 개발자 → PIN 6554. 검색 경과시간/첫 결과 시간, API 요청 수, 후보 노선 수, 오류 수, 최근 검색 내역. 페이지 메모리에만 보유, 수동 초기화·잠금. PIN을 클라이언트 코드에서 읽을 수 있으므로 보안 경계가 아님.
7. **모듈 정리**: 기존 CSS를 styles.css로 추출, 추가 스타일 ui-stabilization.css, 로컬 진단 diagnostics.js로 분리. index.html에서 버전별 URL 로딩. README 재작성. app.js 버스 API·검색·렌더링 로직은 이 빌드에서 유지해 기능적 위험을 줄임.

## 변하지 않는 것
- 이전 V1.4 Build 05의 전체 기능, 인트로(5초), 밝은 테마, 상단 갱신 버튼.
- localStorage 키 ji-bus-v1 및 저장된 API 인증키·즐겨찾기.
- 서버/개인정보 전송 없음. 개발자 진단에 API 키·GPS 좌표·검색 목적지를 기록하지 않음.
